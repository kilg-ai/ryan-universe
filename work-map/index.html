THE GOAL

The desk is released so operators can see attention and next steps.
Daily fit confirmation is still open — on purpose.

No agent logs required. Release ≠ finished acceptance. Expand only when the next workflow is ready — and keep consequential actions as separate decisions.

SEPARATE DECISIONS (TRUST SIGNAL)

Worker OFF · Customer send STOP · Calendar READ-ONLY

Each capability needs its own explicit yes. Approving one never enables the others.
